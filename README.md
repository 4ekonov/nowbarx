# NowBarX

Samsung-style Now Bar for the iOS lock screen. Rootless (Dopamine), iOS 15–17.

## Что умеет (v0.2)
- Капсула в стиле Samsung Now Bar: плотная, тёмная, с настраиваемой прозрачностью.
- Spotify: обложка, название, исполнитель, кнопка play/pause прямо в капсуле;
  в раскрытом виде прогресс и prev / play-pause / next.
- Системный таймер с кольцом прогресса (пауза / стоп в раскрытом виде).
- Будильник по умолчанию выключен; если включить, появляется только за N минут до звонка.
- Несколько событий собираются в стопку карточек. Свайп вверх/вниз по капсуле
  переключает карточки, нажатие на выглядывающую карточку выводит её вперёд.
- Нажатие на капсулу раскрывает её, нажатие на раскрытую карточку сворачивает.
- Штатный плеер на экране блокировки скрывается, пока капсула показывает музыку.
- Настройки: отступ снизу (0–700), сдвиг по горизонтали (±300), ширина и высота капсулы,
  прозрачность, размытие, функции, «только Spotify», вибрация.
  Применяются сразу, респринг не нужен.

## Сборка
1. Установи Theos и iOS SDK (iPhoneOS 15+).
2. В папке проекта: `make package`
3. Готовый `.deb` лежит в `packages/`. Поставь его через Sileo / Filza / `dpkg -i`,
   затем `sbreload`.
4. Зависимость: `preferenceloader` (rootless).

## Отладка
Сборка идёт с `-DNB_DEBUG=1`. В консоль SpringBoard пишутся строки `[NowBarX]`,
а при играющей музыке на экране блокировки дерево view сохраняется в
`/var/mobile/Documents/NowBarX-views.txt` (можно открыть в Filza). Этот файл нужен,
чтобы точно определить класс штатного плеера. Убрать флаг в Makefile после настройки.

## Что нового в v0.3
- Цвет фона капсулы берётся из обложки трека (переключатель «Цвет фона из обложки»).
- Определение таймера переписано: пробуются несколько способов, результат пишется в
  `/var/mobile/Documents/NowBarX-log.txt`.
- Тестовый режим («Тестовые карточки») показывает фиктивные таймер, трек и будильник,
  чтобы проверить стопку без реального таймера.
- Штатный плеер скрывается вместе со своим фоном; можно скрыть надпись «Нажмите Домой…».
- Элементы капсулы сдвинуты от краёв к центру.

## Что нового в v0.4

- **Таймер** читается асинхронно (раньше приложение ждало ответ системы и не дожидалось). Секундомер добавлен.
- **Кнопки «назад / вперёд»** прямо в свёрнутой капсуле плеера (настройка «Кнопки назад / вперёд в капсуле»). Если капсула слишком узкая, они скрываются сами. Ширина по умолчанию теперь 235.
- **Постоянные карточки** (одна за раз, только когда нет трека, таймера, секундомера, будильника): фонарик (с кнопкой выключения), точка доступа, энергосбережение, VPN, зарядка (по умолчанию выключена), погода, экранное время.
  - Погода берётся с wttr.in по IP; экранное время считается самим твиком (время, пока телефон разблокирован, с момента установки).
- Журнал для отладки таймера и секундомера: `/var/mobile/Documents/NowBarX-log.txt`.

## Что нового в v0.5

- **Фонарик** определяется через системный контроллер SpringBoard (SBUIFlashlightController), AVFlashlight и AVCaptureDevice; карточка проверяется раз в секунду.
- **Погода**: геолокация по IP (ipwho.is, запасной ipapi.co) и прогноз с open-meteo. Описание и значок — на русском.
- **Новые постоянные карточки**: запись экрана, низкий заряд, наушники и беззвучный режим (оба экспериментальные, по умолчанию выключены), дата, свободная память.
- **Экранное время** вынесено в отдельную группу настроек со своим переключателем.
- **Скругление углов** пилюли: слайдер 0–100 % (100 — полная пилюля).
- Журнал постоянных карточек: `/var/mobile/Documents/NowBarX-ambient.txt` (что видит твик: фонарик, интерфейсы, погода).

## Что нового в v0.6

- **Отступы внутри капсулы**: отдельно по горизонтали и по вертикали (раздел «Отступы внутри капсулы»).
- **Кнопки по бокам капсулы** (страница «Кнопки на экране блокировки»): две круглые кнопки в стиле iOS слева и справа, по центру высоты капсулы. Настраиваются размер, расстояние от капсулы и действие каждой кнопки.
  - Действия: фонарик, камера, Wi-Fi, Bluetooth, авиарежим, блокировка поворота, энергосбережение, блокировка экрана, респринг (долгое нажатие), пауза/следующий/предыдущий трек, приложения (Настройки, Калькулятор, Часы, Заметки, Телефон, Сообщения, Safari, Wallet, Spotify) и любое приложение по Bundle ID.
  - Включённые переключатели подсвечиваются белым кругом.
- Настройки разделены на страницы: основная, «Постоянные карточки», «Кнопки».

## v0.6.1

- Капсула и кнопки плавно скрываются, когда открыт экран ввода пароля (переключатель «Скрывать на экране ввода пароля» в «Прочее»). Если определение не сработает, смотрите `/var/mobile/Documents/NowBarX-passcode.txt`.

## v0.7

- Капсула плавно уезжает вниз, а боковые кнопки вбок, когда на экране блокировки открыто меню: поиск или «Сегодня», история уведомлений, клавиатура, ввод пароля. Журнал причин: `/var/mobile/Documents/NowBarX-menus.txt`, а при срабатывании дерево видов пишется в `NowBarX-tree-N.txt`.
- Цвет фона капсулы и кнопок (чёрный → серый), плотность фона кнопок.
- Кнопки: анимация нажатия (уменьшение, подсветка, пружина), камера больше не вешает телефон (запуск приложения не блокирует SpringBoard), фонарик включается одним способом без моргания.

## v0.7.1

- Будильник больше не показывается «из ничего» (раньше отсутствующее поле читалось как 00:00): нужен реальный включённый будильник.
- Определение меню переписано: капсула прячется, когда страница экрана блокировки или список уведомлений сдвинуты относительно положения покоя, а также при клавиатуре и вводе пароля. Поиск и «Сегодня» теперь ловятся по сдвигу страницы, без угадывания названий. Диагностика: `NowBarX-menus.txt`, `NowBarX-scrolls-N.txt`.
- Надпись «Нажмите кнопку «Домой»…» ищется ещё и по тексту и скрывается повторно несколько раз в секунду.
- Новая настройка «Замедление анимации» (по умолчанию ×2).

## v0.8 — стиль ColorOS

- Новый внешний вид: прозрачное стекло с тонкой светлой рамкой, синие значки (песочные часы, будильник, секундомер) без кольца, время жирной первой строкой, подпись под ним, синяя круглая кнопка паузы у таймера, светлые круглые боковые кнопки и дуги «( )» по бокам капсулы.
- Всё скрывается одним движением вниз: капсула, дуги и обе кнопки. Скрытие мгновенное (проверка каждый кадр, сдвиг шторки уведомлений ловится сразу).
