# NowBarX

Samsung-style Now Bar for the iOS lock screen. Rootless (Dopamine), iOS 15–17.

## Что умеет (v0.1)
- Капсула внизу экрана блокировки, нажатие раскрывает её пружинной анимацией.
- Spotify: обложка, название, исполнитель, прогресс, prev / play-pause / next.
- Системный таймер (пауза / стоп) и ближайший будильник (в пределах 12 часов).
- Свайп влево/вправо переключает карточки, свайп вниз сворачивает.
- Настройки: отступ снизу, сдвиг по горизонтали, размер, какие функции показывать,
  «только Spotify», вибрация. Применяются сразу, респринг не нужен.

## Сборка
1. Установи Theos и iOS SDK (iPhoneOS 15+).
2. В папке проекта: `make package`
3. Готовый `.deb` лежит в `packages/`. Поставь его через Filza / Sileo / `dpkg -i`,
   затем `sbreload`.
4. Зависимость: `preferenceloader` (rootless).

## Отладка
Сборка идёт с `-DNB_DEBUG=1`, в консоль SpringBoard пишутся строки `[NowBarX]`
(состояния таймеров, будильник, источник медиа). Смотреть: `log stream` или
Console на Mac. Убрать флаг в Makefile после настройки.

## Что нужно проверить на устройстве
- Значения `MTTimer.state` (в коде допущено: 2 = идёт, 3 = пауза).
- Имена методов пауза/стоп таймера (`pauseTimer:`, `resumeTimer:`, `removeTimer:`).
- Поведение поверх ввода пароля и в Notification Center.
